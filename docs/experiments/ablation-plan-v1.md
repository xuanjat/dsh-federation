# Murmuration消融实验计划 v1（A0基线 vs A1联邦）

> 发起：米线lead（tlf指令2026-11-09）。执行：糯米。目的：受控对照"普通DSH单会话"与"部署Murmuration架构的DSH集群"的执行效率差异，为论文§6提供existence evidence之外的受控证据。
> 性质：任务内容全部抽象化（科学实验/文本撰写/论文写作三类），结果只报数字不报内容。

## 1. 假设（可证伪）

- H1（并行收益）：对可并行任务批，A1总完成时间（makespan）< A0。
- H2（上下文经济）：A1每任务读入会话上下文的字节数 < A0（指针交付，负载不进上下文）。
- H3（协同开销）：A1的会话轮次数与消息条数 > A0（量化协同税）。
- H4（校验质量）：A1首次sha256校验通过率 >= A0（工具层校验 vs 会话内人工校验）。

## 2. 两条臂

- **A0基线**：单个DSH会话顺序执行全部任务。无房间、无游标、无跨机。任务清单文件驱动，逐条做完做下一条。
- **A1联邦**：Murmuration协议部署。最小配置=糯米的两个独立DSH会话经房间协同（本地联邦）；推荐配置=糯米+云吞跨机（房间走OV，payload走scp/sshfs）。若云吞时段不可用，退最小配置并在结果注明。
- 公平性：两臂同模型、同温度、同超时上限；A0禁用任何房间式协调；A1任务交接必须走房间协议（禁直接操作对方shell）。

## 3. 任务组合（6任务=3类×2）

| id | 类型 | 任务 | 可并行 |
|---|---|---|---|
| T1 | 科学实验 | 对给定CSV（种子数据自造）做描述统计+出1幅图 | 是 |
| T2 | 科学实验 | 蒙特卡洛估计π（10^6样本），误差<0.01% | 是 |
| T3 | 文本撰写 | 500字实验报告一份（基于T1结果→构成依赖链） | 否（依赖T1） |
| T4 | 文本撰写 | 将给定中文段落改写为学术风格（自备样例段） | 是 |
| T5 | 论文写作 | 对给定短文样例做一轮修订（自备样例，改3处逻辑+5处语言） | 是 |
| T6 | 论文写作 | 为样例短文写150词英文摘要 | 否（依赖T5，测接力） |

依赖链：T1→T3→（T5→T6可并入）。T6依赖T5产物，测试工作接力（handoff）。

## 4. 重复与随机化

每臂跑n=3轮；轮内任务顺序按拉丁方轮换（消顺序效应）；两臂任务措辞逐字相同。建议夜间低负载窗口（22:30后），两臂同窗口内完成。

## 5. 指标与测量口径

| id | 指标 | 测量方法 |
|---|---|---|
| E1 | makespan（分） | 任务批起点（清单下发）到末任务完成标记的墙钟时间 |
| E2 | 单任务时延（分） | 任务开始→完成（A1从房间消息mid秒级时间戳取；A0从任务日志） |
| E3 | 上下文字节数 | 会话内read类操作读入的字节总量（负载读取 vs 指针校验分开计） |
| E4 | 轮次/消息数 | 会话轮次数；A1另计房间消息条数（按type分列） |
| E5 | 首次通过率 | 首次产出即sha256校验通过的交付占比；重试次数单列 |
| E6 | 人工干预次数 | 会话外人工介入计数（含超时手动补跑） |

## 6. 流程

1. 准备：建results/a0/与results/a1/目录；自造种子数据与样例文本（两臂共用同一份）；确认模型配置一致。
2. A0×3轮：单会话顺序执行，每任务开始/结束写一行任务日志（ts、task_id、事件）。
3. A1×3轮：按协议部署（房间骨架+游标+值守），任务经data指针投递，交付经sha256校验回ack；A1-cross时payload走scp。
4. 汇总：按§5填results/summary.csv（列：arm,round,task_id,E1..E6）。
5. 回传：summary.csv+两份任务日志样例，sha256指针投room inbox/mixian.md，回ack。

## 7. 红线

- 任务内容不进房间（只传指针与数字）；种子数据自造，不涉真实科研数据。
- 不跨机shell；A1-cross下文件只走既有通道。
- 任一步骤卡死>30分钟：发note报房说明现场，不静默重试；两臂超时上限统一90分钟/任务。

## 8. 交付与时间

- 交付：results/summary.csv + 实验记录.md（含异常记录）。
- 期望窗口：3轮×2臂约需一夜到两夜（视负载）。完成或受阻都在房间回执。
- 结果用途：论文§6受控对照小节（只引用数字，不引用任务内容）。
