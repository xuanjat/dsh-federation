Personal LLM-agent harnesses now run simultaneously on many heterogeneous machines (workstations, cloud servers, LAN boxes, offline nodes), yet each instance is a silo: its sessions, files, and learned lessons do not cross machine boundaries, and letting one agent operate another machine's shell is a security red line. We present Murmuration, a method framework that federates independent agent instances through a single shared, plain-text context database, adding no broker or middleware beyond that store. Its core is a semantic-level transport model: messages carry only speech-act headers (five performatives), wire-level identities, and wall-clock timestamps; anything larger than a small threshold travels as a content-addressed pointer (path + SHA-256 + byte count) that is verified outside any agent's context window. We formalize a message calculus and derive three cost properties — design invariants implied by the payload threshold and the manifest discipline, not independently established empirical results: per-delivery context cost scales with the pointer list rather than payload bytes, and drops to a constant header when the manifest itself travels as a file; novelty detection is O(1) via fixed-width timestamp comparison; and k-hop relay never re-pays payload context, since pointer forwarding and digest verification are idempotent. Around the transport we specify organizational governance: a versioned, incident-driven handbook with red lines, role-scoped acknowledgment obligations, and time-triggered watchkeeping suited to turn-based agents. We report a sanitized eleven-day (elapsed) field deployment across five heterogeneous machines (protocol v1.0→v1.4, eight role types, 45 cross-machine lessons, 13 archived incidents, deliveries of up to 1,300 files, each verified by per-file SHA-256 corruption checks) and a 49-system novelty assessment. Within the window the room carried 283 structured messages (mean 26/day, peak 49/day) — 37 typed data deliveries, 29 asks, and 89 acknowledgment discharges — with more than three thousand per-file SHA-256 checks at byte equality and zero mismatches; payload content (scientific-experiment pipelines, document drafting, paper writing) never enters this paper, only counts and shapes. A controlled same-window ablation (three rounds x six abstracted tasks, Latin-square order) corroborates the field evidence: the federation arm cut makespan by 34% with three-times-lower variance, at +1.3 turns and +57% context bytes per task, with verification parity (18/18 first pass per arm). Per our search (2026-11), no public scheme combines all of: heterogeneous cross-machine instances, a shared plain-text context database as the sole substrate, versioned incident-driven handbook governance, pointer-based delivery-integrity checks, turn-driven watchkeeping, and field evidence; we state claims at a deliberately conservative level. Keywords: multi-agent systems, LLM agents, agent communication, semantic communication, content addressing, coordination artifacts, organizational governance, field deployment.
